# peripheral-sinclair-zx-spectrum-interface1

Sinclair's ZX Interface 1 and up to eight ZX Microdrives.

| Crate | Registry |
|---|---|
| [`emu198x-peripheral-sinclair-zx-spectrum-interface1`](crates/emu198x-peripheral-sinclair-zx-spectrum-interface1) | [crates.io](https://crates.io/crates/emu198x-peripheral-sinclair-zx-spectrum-interface1) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Spectrum machines that accept one.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
